# Multi-Vendor Agent Architecture

```text
skills/ + plugin.json
        |
        v
.claude/skills/  .agents/skills/  .github/skills/
                  (also read by Cursor)
```

## Canonical Sources

Edit directly:

| Path | Purpose |
|---|---|
| `AGENTS.md` | Repo entrypoint and skill router |
| `skills/*/SKILL.md` | Canonical skill content |
| `plugin.json` | Root manifest, agent-plugins.org v1.0.0 |
| `docs/constitution.md` | Governance and quality gates |
| `helpers/` | JSON scaffolds and build templates |
| `spec-files/` | Customer spec templates |
| `customizations/org/` | Org-wide standards |
| `customizations/team/` | Team standards |
| `customizations/developer/` | Local developer preferences |

Not generated by this repo's scripts:

| Path | Purpose |
|---|---|
| `.claude-plugin/plugin.json` + `.claude-plugin/marketplace.json` | Claude Code's own plugin manifest, used by `claude plugin install` |
| `.agents/plugins/marketplace.json` | Codex marketplace registration for this repo |

## Generated Local-Repo Mirrors

Do not edit directly. Real copies, not symlinks.

| Path | Vendor |
|---|---|
| `.claude/skills/` | Claude Code |
| `.agents/skills/` | Codex CLI, Cursor |
| `.github/skills/` | GitHub Copilot |

## Workflow

```bash
scripts/generate-vendor-wrappers.sh
scripts/check-generated.sh
```

## Install & Invoke

| Vendor | Install | Invoke |
|---|---|---|
| Claude Code | `claude plugin install` | `/skill-name` |
| Codex CLI | `codex plugin add` | `$skill-name`, `/skills`, or auto-route |
| Cursor | Plugin marketplace | `/skill-name` |
| GitHub Copilot | `gh skill install` | `/skill-name` or auto-route |

Cursor also reads `.agents/skills/` — no separate mirror needed.

See `docs/vendor-install.md` for exact commands.
